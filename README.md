# ⚖️ Obesity Classification Project

A Machine Learning classification project that predicts obesity levels based on lifestyle, physical, and dietary habits using multiple features and machine learning models.

---

## 📌 Dataset Overview
The dataset contains **2111 samples** with 17 features related to:
- Physical attributes (Age, Height, Weight)
- Eating habits
- Physical activity
- Lifestyle factors
- Transportation type

Target variable:
- **NObeyesdad (Obesity Level)**

---

## 🚀 Project Goal
To build a machine learning model that classifies individuals into different obesity levels based on their lifestyle and health-related features.

---

## 📊 Features
- Data preprocessing and cleaning
- Handling categorical and numerical data
- Exploratory Data Analysis (EDA)
- Feature encoding and scaling
- Training multiple ML classification models
- Model evaluation and comparison

---

## 🛠️ Technologies Used
- Python

- Scikit-learn

---

## 📈 Workflow
1. Load dataset using Pandas
2. Explore dataset structure using `df.info()`
3. Handle categorical variables
4. Encode and scale features
5. Split data into training and testing sets
6. Train multiple classification models
7. Evaluate models using:
   - Accuracy Score
   - Confusion Matrix
   - Classification Report
